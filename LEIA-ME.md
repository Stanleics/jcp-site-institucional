# Site novo, João de Carvalho & Pêgo Advocacia

Site estático (HTML, CSS e um JS de menu). Identidade visual tirada de `../pirescarvalhooliveira.adv.br`
(fundo #071317, dourado #CBA672, Montserrat, cantos assimétricos, botões em pílula).
Textos e fotos vêm da cópia do site antigo.

Ver localmente: `python3 -m http.server 8912` dentro desta pasta.

Páginas: index, quem-somos, areas-de-atuacao, trabalhista, inss, familia-e-sucessoes,
imobiliario, direito-medico, acidentes-de-trabalho, na-midia, contato.

`../_gerador/` tem o script que gerou as páginas a partir do conteúdo recuperado
(`extract.py` lê `../site`, `build.py` escreve aqui).
